새 응답자료 만들기

원본 프로그램과 같은 방식입니다. 문항 수와 ID 캐릿수를 입력하고, 각 문항의 정답·답지 수·분석 포함 여부를 표에 입력한 뒤 만들기를 누르면 .dat 편집 화면이 열립니다. 학생 응답은 한 줄에 한 명씩(ID 뒤에 응답, 공백=무응답) 이어서 입력합니다.

데이터 편집 (.dat)

원본 .dat 형식 그대로 편집합니다. 첫 줄은 문항수와 ID 캐릿수, 이어서 정답키·답지 수·분석 포함(y/n) 줄, 그 아래 학생 응답(한 줄에 한 명, ID 뒤에 응답, 공백=무응답)을 입력합니다. 적용하면 다시 분석합니다.
