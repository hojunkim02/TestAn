# TestAn Web

원본 **TestAn 1.0 for Windows** (VB6, 2000)을 현대적인 정적 웹 앱으로 포팅한 고전적 문항분석(CTT) 도구입니다.
GitHub Pages로 바로 배포할 수 있으며, 모든 파싱·계산은 브라우저에서 수행됩니다(서버 없음).

## 사용 방법

1. 응답 데이터(CSV · JSON · Excel)를 업로드하거나 "샘플 데이터로 보기" 클릭
2. 탭에서 점수 결과 / 문항 분석 / 답지 분석 / 그래프 / 결과 파일 확인
3. 결과를 점수 CSV · 문항 분석 CSV · 전체 리포트 JSON으로 다운로드

## 데이터 형식

### 응답 CSV (`id,q1,...,qN` + 선택적 메타 행)

```csv
id,q1,q2,q3,q4
KEY,4,3,1,3          ← 정답 (선택)
OPTIONS,4,4,2,4      ← 답지 수 (선택)
INCLUDE,y,y,y,n      ← 분석 포함 여부 (선택)
0001,2,3,1,3         ← 학생 응답 (빈 칸 = 무응답)
0002,2,,1,3
```

- KEY 행이 없으면 별도의 정답 파일(CSV/JSON)을 업로드해야 채점됩니다.
- Excel(`.xlsx`) 파일은 첫 시트를 CSV로 읽어 동일하게 처리됩니다(SheetJS, CDN 로드 필요).

### JSON

```json
{
  "items":    [{ "no": 1, "key": "4", "options": 4, "include": true }],
  "students": [{ "id": "0001", "responses": ["2", "3", "", "3"] }]
}
```

`responses`의 빈 문자열(`""`)은 무응답입니다. "데이터 편집 (JSON)"은 이 형식으로 편집합니다.

### 결과 파일

| 파일 | 내용 |
| --- | --- |
| `scores.csv` | rank, id, score, percent, correctCount |
| `items.csv` | 문항별 난이도/상관계수/상하위 정답률/변별도/제외 시 α |
| `report.json` | 전체 통계 + 문항·답지·학생 상세 리포트 |

## 분석 지표 — 원본 TestAn 1.0과 동일

- 문항별: 난이도, 문항점수-총점 상관계수(점수이분상관), 상/하위 27% 정답률과 변별도, 답지별 응답비율과 답지-총점 상관, 매력적 오답/부정 변별문항 표시, 문항 제외 시 신뢰도
- 전체: 평균, 표준편차(모집단), 분산, 최고/최저, 중앙값, 왜도, 첨도, Cronbach α, 측정오차(SEM), 평균 난이도/변별도
- 상·하위 27% 집단: 경계 점수의 동점자를 포함한 집단 크기와 점수 범위

### 검증

원본 매뉴얼의 `answer.dat` 분석 예시 수치 25개 항목(평균 45.059, 표준편차 5.282, Cronbach α 0.633, 측정오차 3.201, 문항 제외 시 α 등)과
전부 일치함을 `node js/test.js` 골든 테스트로 검증했습니다 (CSV 경로로 동일 수치 재현).

## 원본 기능 대응표

| 원본 TestAn 1.0 | TestAn Web |
| --- | --- |
| 파일 → 자료/결과파일 설정 | 업로드 + 생성할 결과 파일 선택(CSV/JSON) |
| 편집 → 입력자료 편집 | 데이터 편집 모달 (JSON 편집 → 즉시 재분석) |
| 파일 → 새 응답자료파일 생성 | 생성 마법사 (문항별 정답/답지수/포함여부 + 학생 응답 CSV 합성) |
| 보기 → 분석결과/개별점수/그래프/정렬결과 | 문항·점수·답지·그래프 탭 + 결과 파일 탭 |
| 인쇄 | 인쇄 버튼 (활성 탭만 인쇄) |
| 도움말 → 정보 | 정보 다이얼로그 |

## 디렉토리 구조

- `index.html`, `css/`, `js/` — 웹 앱 (GitHub Pages 배포 대상)
- `sample-data/` — 샘플 데이터 (현대 CSV 포맷)
- `tools/convert-dat.js` — 레거시 `.dat` → CSV 변환기 (기존 자료 마이그레이션용)
- `Orgin/` — 원본 VB6 실행 파일, 런타임, 레거시 테스트 데이터(보관용)

Repository → Settings → Pages → Source: `main` 브랜치, 루트(`/`) 선택.
