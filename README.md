# TestAn Web

원본 **TestAn 1.0 for Windows** (VB6, 2000)을 정적 웹 앱으로 포팅한 고전적 문항분석(CTT) 도구입니다.
GitHub Pages로 바로 배포할 수 있으며, 모든 파싱·계산은 브라우저에서 수행됩니다(서버 없음).

## 사용 방법 (원본 TestAn 1.0의 기능과 1:1 대응)

1. 응답 데이터 파일(`.dat`)을 업로드하거나 "샘플 데이터로 보기" 클릭
2. 탭에서 점수 결과 / 문항 분석 / 답지 분석 / 그래프 / 결과 파일 확인
3. 결과를 `.out` / `.scr` / `.grp` / `.srt` 파일로 다운로드

### 원본 기능 대응표

| 원본 TestAn 1.0 | TestAn Web |
| --- | --- |
| 파일 → 자료파일/결과파일 설정 | 응답/정답 데이터 업로드 + 생성할 결과 파일 선택(.out/.scr/.grp/.srt, 정렬 기준 _diff/_disc) |
| 분석실행 → 확인 | 업로드 즉시 자동 분석 (상태 표시) |
| 보기 → 분석결과(.out) | 문항 분석 탭 + 결과 파일 탭(.out 내용 그대로) |
| 보기 → 개별점수(.scr) | 점수 결과 탭 + 결과 파일 탭(.scr) |
| 보기 → 그래프(.grp) | 그래프 탭(막대/선 그래프 + 도수·백분율·누가 백분율 표) |
| 보기 → 정렬결과(.srt) | 문항 분석 탭 정렬 옵션 + 결과 파일 탭(_diff/_disc) |
| 편집 → 입력자료 편집 | 데이터 편집 (모달에서 .dat 직접 편집 후 재분석) |
| 파일 → 새 응답자료파일 생성 | 새 자료파일 생성 마법사 (문항수·ID캐릿수, 문항별 정답/답지수/포함여부, 연결 파일 합성) |
| 파일 → 인쇄 | 인쇄 버튼 (활성 탭 인쇄) |
| 도움말 → TestAn 정보 | 정보 버튼 |

## 데이터 형식 (`.dat`) — 원본 TestAn 1.0 매뉴얼 표 14 기준

```
문항수 [공백] ID캐릿수    ← control line: 1-3열 문항수(최대 200), 9-10열 ID 캐릿수(최대 99)
정답키                    (문항수 길이)
답지 수                   (문항수 길이)
분석 포함 여부 y/n        (문항수 길이)
학생 레코드...            (앞부분은 ID, 마지막 문항수 길이가 응답, 공백=무응답)
```

점수는 맞힌 문항 수(문항당 1점)입니다.

## 분석 지표 — 원본 TestAn 1.0의 .out 결과와 동일

- 문항별: 문항 난이도, 문항점수-총점 상관계수(점수이분상관), 상/하위 27% 정답률과 변별도(정답비율 차), 답지별 응답비율(전체/상위/하위)과 답지-총점 상관계수, 매력적 오답/부정 변별문항 표시, 문항 제외 시 신뢰도
- 전체: 평균, 표준편차(모집단), 분산, 최고/최저, 중앙값, 왜도, 첨도, Cronbach α, 측정오차(SEM), 평균 난이도/변별도
- 상·하위 27% 집단: 경계 점수의 동점자를 포함한 집단 크기와 점수 범위
- 학생별: 득점(맞힌 문항 수), 순위

### 검증
원본 매뉴얼(그림 14~16)의 `answer.dat` 분석 예시 수치 25개 항목(평균 45.059, 표준편차 5.282, Cronbach α 0.633, 측정오차 3.201, 문항 제외 시 α 등)과
전부 일치함을 `js/test.js` 골든 테스트로 검증했습니다.

## 디렉토리 구조
